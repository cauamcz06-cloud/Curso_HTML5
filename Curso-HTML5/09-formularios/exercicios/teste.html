Micro Projeto: Meu Primeiro Portfólio Semântico

1. O Contexto

Você foi contratado para criar a estrutura inicial da página de um desenvolvedor. Antes de pensar em cores, fontes ou alinhamentos (CSS), sua missão é construir a fundação do site utilizando exclusivamente HTML. O navegador e os mecanismos de busca (como o Google) precisam entender perfeitamente o que é o cabeçalho, o que é o conteúdo principal, o que é um menu e o que é o rodapé.

REGRA DE OURO: ZERO CSS E JAVASCRIPT!
Neste projeto, você não deve usar a tag <style>, atributos de estilo ou arquivos CSS/JS. O foco é 100% na semântica. O visual no seu navegador ficará simples, de cima para baixo (em blocos estruturais padrão), e está tudo bem!

2. Requisitos do Projeto

Você deve utilizar todas as 13 tags semânticas discutidas em sala de aula. Abaixo está o seu checklist:

<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
<figure>
<figcaption>
<mark>
<time>
<details>
<summary>

4. Guia de Implementação (Dicas)

Para não se perder, aqui vai uma sugestão de como mapear o desenho acima para o seu código HTML:

Área do Layout Tags Semânticas Sugeridas Dica de Uso
Topo (Logotipo e Menu) <header>, <nav>, <figure>, <figcaption> Envolva tudo no header. O logotipo preto pode ser uma imagem dentro de um <figure> e "seu nome" no <figcaption>. Os links entram no <nav>.
Título Principal <main>, <mark> Abra a tag <main> para iniciar o conteúdo. Use <mark> para grifar a frase "apenas html com layout adequado...".
Coluna de Projetos <aside> Como é uma barra lateral de navegação secundária, agrupe essa lista dentro de um <aside>.
Experiência, Educação e Avaliações <section>, <article>, <time> Crie uma <section> para cada tema. Cada experiência de trabalho ou cada avaliação (caixinhas com borda arredondada) é um conteúdo independente, ou seja, um <article>. Use <time> para marcar datas ou anos na experiência.
Lista de Cursos (Educação) <details>, <summary> Crie uma área expansível onde o <summary> seja "Cursos que fiz:" e, ao clicar, exiba a lista de cursos.
Rodapé <footer> Feche a página com a tag de rodapé contendo os direitos autorais.
